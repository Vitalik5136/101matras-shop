ИНТЕРНЕТ-МАГАЗИН 101MATRAS — КАК ЗАПУСТИТЬ

Сайт сам берёт товары, цены и наличие из выгрузки Хорошопа (обновляет каждые 3 часа).
Заказы уходят в KeyCRM. Оплата — картой через monobank, наложенным платежом или в магазине.

---

## Шаг 1. Загрузить файлы на GitHub

1. Скачайте из чата все 11 файлов в одну папку на компьютере, например «101matras-shop» на рабочем столе:
   server.js, package.json, settings.js, feed.js, keycrm.js, monobank.js, novaposhta.js, index.html, app.js, styles.css, favicon.svg
2. Откройте https://github.com/new (страница создания репозитория).
3. В поле **Repository name** (Имя репозитория) впишите `101matras-shop`.
4. Отметьте **Private** (Приватный), чтобы код никто не видел.
5. Нажмите зелёную кнопку **Create repository** (Создать репозиторий).
6. На открывшейся странице нажмите ссылку **uploading an existing file** (загрузить существующий файл).
7. Откройте свою папку, выделите все 11 файлов (Ctrl+A) и перетащите их в окно браузера.
8. Подождите, пока внизу появится список всех 11 файлов, и нажмите зелёную кнопку **Commit changes** (Сохранить изменения).

## Шаг 2. Запустить на Railway

1. Откройте https://railway.app/new.
2. Нажмите **Deploy from GitHub repo** (Развернуть из репозитория GitHub) и выберите `101matras-shop`.
3. Railway сам поймёт, что это Node.js, и запустит сайт за 1–2 минуты.
4. Откройте созданный сервис → вкладка **Settings** (Настройки) → блок **Networking** (Сеть) → кнопка **Generate Domain** (Создать домен).
   Появится адрес вида `101matras-shop-production.up.railway.app` — это адрес магазина.

## Шаг 3. Вставить ключи (вкладка Variables / «Переменные»)

В сервисе откройте вкладку **Variables** (Переменные) → кнопка **New Variable** (Новая переменная).
Слева пишете имя, справа — значение. После добавления Railway сам перезапустит сайт.

| Имя переменной | Что вставить | Где взять |
|---|---|---|
| `KEYCRM_API_KEY` | ключ KeyCRM | KeyCRM → «Налаштування» (шестерёнка) → «Загальні» → блок «API ключ» → «Згенерувати» / скопировать |
| `ADMIN_KEY` | любой ваш пароль, например `matras2026` | придумайте сами — нужен для страницы проверки |
| `SHOP_PHONE` | телефон магазина, например `+380 67 123 45 67` | показывается покупателям |
| `PUBLIC_URL` | адрес из шага 2, с `https://` в начале | например `https://101matras-shop-production.up.railway.app` |
| `NP_API_KEY` | ключ Новой почты | ваш личный кабинет НП → «Налаштування» → «Безпека» → «API ключ» (тот же, что уже используете для Мономаркета). С ним покупатель выбирает город и отделение из списка |
| `MONO_TOKEN` | токен monobank (plata by mono) | кабинет https://web.monobank.ua → раздел интернет-эквайринга → токен для интеграции. Без него онлайн-оплаты на сайте просто не будет |
| `KEYCRM_SOURCE_ID` | номер источника «Сайт» | необязательно: см. шаг 4 |
| `TG_BOT_TOKEN` и `TG_CHAT_ID` | токен бота и ваш chat id | необязательно: копия каждого заказа в Telegram. Если KeyCRM вдруг не ответит, заказ всё равно не потеряется |

## Шаг 4. Проверить, что всё подключено

Откройте в браузере: `https://ВАШ-АДРЕС/admin?key=ВАШ_ADMIN_KEY`

Там будет список с ✅ / ❌:
- **Каталог** — сколько моделей загружено (сейчас около 262).
- **KeyCRM** — подключён ли, и список ваших «Источников продаж» с номерами.
  Если хотите, чтобы заказы сайта попадали в конкретный источник — создайте в KeyCRM источник «Інтернет-магазин»
  (в настройках KeyCRM, раздел источников заказов), посмотрите его номер на этой странице и впишите в переменную `KEYCRM_SOURCE_ID`.
  Если не указать — сайт сам выберет источник со словом «сайт» / «магазин» в названии.
- **monobank**, **Нова пошта**, **Telegram** — подключены или нет.

## Шаг 5. Сделать пробный заказ

Закажите на сайте что-нибудь недорогое с оплатой «Накладений платіж» и проверьте, что заказ появился в KeyCRM.
Если подключили monobank — сделайте ещё один заказ с оплатой картой: после оплаты в заказе KeyCRM появится отметка об оплате.

## Как это устроено

- **Товары**: модели группируются по `group_id` из выгрузки, каждый размер — отдельный вариант со своим артикулом (`vendorCode`). Именно артикул уходит в KeyCRM.
- Позиции «розмір під замовлення / м²» на сайт не выводятся (у них цена за м², а не за штуку).
- «В наявності» — когда в выгрузке `available="true"`, иначе «Під замовлення» (купить всё равно можно, менеджер уточнит срок).
- Цены при оформлении всегда пересчитываются на сервере по выгрузке — подменить цену в браузере нельзя.
- Свой домен (например `shop.101matras.ua`) подключается в Railway: Settings → Networking → **Custom Domain** (Свой домен).

## Файлы

- `server.js` — сервер: каталог, заказы, оплата, страница проверки
- `feed.js` — разбор выгрузки Хорошопа
- `keycrm.js`, `monobank.js`, `novaposhta.js` — подключения к сервисам
- `settings.js` — настройки (магазины для самовывоза, адрес выгрузки и т. п.)
- `index.html`, `app.js`, `styles.css`, `favicon.svg` — сам сайт (страница, логика, оформление, значок)
- `package.json` — список того, что Railway должен установить
